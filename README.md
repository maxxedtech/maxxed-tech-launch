# Maxxed Tech Launch Site

Official marketing website for **Maxxed Tech** built with React, TypeScript, Vite, and Tailwind CSS.

## What this project includes
- Animated homepage experience with modern gradients and motion effects.
- Multi-page company site (Home, About, Services, Contact).
- Light and dark mode support with persisted user preference.
- Reusable UI components using shadcn/ui.

## Local development
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
npm run preview
```

## Tech stack
- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- shadcn/ui
